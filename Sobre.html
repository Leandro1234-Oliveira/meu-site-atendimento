Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de melhorar o atendimento e organização de senhas em ambientes de espera, como clínicas, repartições públicas ou serviços gerais.

A interface foi pensada para ser intuitiva, acessível e visualmente agradável, com recursos que ajudam tanto os usuários quanto os atendentes.

O sistema permite o controle e visualização de senhas geradas, além de armazenar localmente os dados durante o uso.

Este site é parte de um projeto estudantil voltado ao aprendizado prático de desenvolvimento web utilizando HTML, CSS e JavaScript.

Projeto desenvolvido por Leandro Oliveira Melo e Guilherme Gomes dos Santos,
alunos do curso de Análise e Desenvolvimento de Sistemas (ADS),
na disciplina de Algoritmo e Lógica de Programação com o professor Lobianco,
no primeiro semestre.

Projeto concluído em 30 de setembro de 2025.
